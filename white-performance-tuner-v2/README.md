# WHITE PERFORMANCE SHOP — Tuningrechner (Echte Teilebilder)

Vollständiges Node.js + Express Projekt mit echten Fotomotiven für sämtliche Tuning-, Leistungs-, Wartungs- und Werkstattartikel sowie Foto-Upload im Adminbereich.

## Deployment auf GitHub & Render
1. Lade den **Inhalt** dieses Ordners direkt in dein GitHub-Repository hoch (`package.json` und `server.js` müssen im Hauptverzeichnis liegen).
2. Wähle in Render **New -> Web Service**, verbinde das Repository und stelle sicher, dass **Language/Runtime = Node** eingestellt ist.
3. Build Command: `npm install` | Start Command: `npm start`.
